First release of Vesper.

- Immersive artwork and a customizable home carousel.
- Cast, crew, related titles, and episode browsing.
- Search and a library for your favorites.
- Watch in VLC or Infuse.

## Install

Sign the unsigned `Vesper.ipa` and install it on **iOS 27 or later**. In Settings, add your TMDB credentials and add-ons, then choose VLC or Infuse.

Use add-ons that provide HTTP/HTTPS sources; there is no built-in torrent engine. Check the IPA against `SHA256SUMS.txt` if needed.
