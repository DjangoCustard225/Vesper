# Vesper 0.1

The first Vesper release: a native SwiftUI home for movies and series on iPhone and iPad.

## Highlights

- Liquid Glass controls, white accents, immersive artwork, and pull-down poster zoom.
- Configurable, swipeable home hero and automatically paginated catalogs.
- TMDB discovery and enriched metadata, title logos, cast portraits, and related titles.
- Native season selection and horizontal episode cards with original-resolution artwork.
- Crew roles in a native sheet, with image-free cast and crew entries hidden.
- Search from the tab bar, with results opening in full-screen detail pages.
- Stremio-compatible add-ons, a local library, and VLC/Infuse playback.
- Quby-inspired app icon and source cards with interactive scroll effects.

## Install

Download `Vesper.ipa`, sign it with your preferred signing tool, and install it on **iOS 27 or later**. Configure your TMDB key and add-ons in Settings, then choose VLC or Infuse as the player.

- App version: **0.1**
- Build: **1**
- Bundle ID: **`app.vesper`**
- Package: **unsigned, ARM64**

`SHA256SUMS.txt` provides the IPA checksum. The new bundle ID installs separately from older builds; credentials and library data do not automatically transfer.

## Current limits

Vesper does not include a built-in player, on-device torrent engine, downloading, or Stremio account sync. Use add-ons that provide playable HTTP/HTTPS sources. External players manage subtitles and new playback progress. No streaming server configuration screen is included.

Validation: **78 core tests pass; iOS 27 release compilation and IPA packaging pass.** Native UI behavior and real-provider playback still require device validation.
